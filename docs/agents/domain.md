# Documentación del dominio

Este proyecto usa un único contexto. Antes de explorar una parte del código, leer `GLOSSARY.md` y las decisiones pertinentes en `docs/adr/`, si existen. Su ausencia no bloquea el trabajo: `domain-modeling` los crea cuando se definan términos o decisiones.

Usar los términos del glosario en issues, pruebas y propuestas. Si una propuesta contradice una decisión registrada, señalarlo expresamente antes de cambiarla.
